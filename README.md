# -sprint7-final-project

Este repositorio contiene el análisis realizado durante el Sprint 7 Análisis ConnectaTel.

El dataset `Análisis ConnectaTel` incluye  comportamiento de los clientes de una empresa de telecomunicaciones en Latinoamérica, ConnectaTel. 

## 📂 Contenido del repositorio

- `notebooks/everpeak_analysis.ipynb`
  → Notebook principal con limpieza,  distribuciones, outliers y conclusiones.

[![Open In Colab](https://colab.research.google.com/drive/1Usumw72Rrc3DpFsv1Y0Ys2L-u5kMHoKh)](URL_DEL_NOTEBOOK_EN_GITHUB)

## 📘 Cómo reproducir el análisis

1. Abre `notebooks/Análisis ConnectaTel`
2. Ejecuta las celdas en orden
3. El notebook carga automáticamente el dataset desde `/data/` o desde un enlace público (según corresponda)

## 🧠 Objetivo del análisis

 identificar patrones de consumo, diseñar estrategias de retención y sugerir mejoras en los planes ofrecidos por la empresa.
- Analizar comportamientos, distribuciones y outliers
- Generar insights para el equipo de Estrategia e Integración de EverPeak
